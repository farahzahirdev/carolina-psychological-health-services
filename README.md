# Carolina Psychological Health Services Landing Page

Intake landing page for **Carolina Psychological Health Services** (Jacksonville, NC) focused on TMS (Apollo) and Spravato® for treatment-resistant depression.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- GoHighLevel embeds (`go.4tms.com`) for booking calendar + inquiry form

## Brand

Colors and typography follow [cphsnc.com](https://cphsnc.com/): teal (`#6AAFAA`), navy (`#283343`), coral accent (`#EFA466`), cream, Lora + Poppins.

## CTAs

- Primary: Book your Free Consultation → `#book` (calendar embed)
- Secondary: Find out if you Qualify → `#qualify` (form embed)
- Phone: `(910) 996-2843` (click-to-call)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
